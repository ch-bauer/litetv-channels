Adverts
Addresses the television resolves and plays. They go at the front of a break with the trailer last, so a break ends on what the channel is about to show. There is no length to type: the plugin asks how long the video is and which parts get skipped, and sizes the break by what is left.
Trailers
What a break advertises, and how often one happens.
A trailer is aired in a break for something the channel is about to show. Almost every trailer a library holds is a YouTube link rather than a file; the server resolves it to a stream the television can play, and skips the parts that are not the trailer.
The programme a break advertises is not the next one — it is the one that many places ahead, the way a channel trails the film after this one. Set it to 1 and a break advertises whatever follows it.
Why there is no length to type
A trailer from YouTube is rarely only the trailer. The uploader wraps it in a branded card and a plea to subscribe, and the television skips both — so the number that matters is not how long the video is, but how long it plays for.
Nobody can type that. The plugin asks YouTube for the length and SponsorBlock for the parts that get skipped, and the break is sized by what is left.

Where channels play
Channel viewing is recorded against this account, never yours.
Which is what keeps channels out of Continue Watching, Next Up and the watched flags. The account is created on first use, hidden from the login screen, and can do nothing but play.

Two things worth knowing. Anyone who can reach this server's API can ask for this account's token, so on a server with several people and libraries not everyone may see, restrict this account to match in Dashboard → Users. And the same title watched deliberately while a channel is on will not be recorded either — it is the account that decides, not what is playing.
