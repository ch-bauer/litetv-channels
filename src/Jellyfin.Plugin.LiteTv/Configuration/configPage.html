LiteTV Channels

Master switch for the playback overlays (channel bug, next-up, pause panel) and the two options below. Web client only (browser and apps that embed the web UI). After installing or updating the plugin, hard-refresh the browser (Ctrl+F5) once.
Adds a "TV-Sender" entry to the library that every client can browse. Playing a channel there joins whatever is on air, at the live position.
Puts the channels and their whole schedule into the server's own Live TV guide, so native clients get a proper grid without the injected UI. Switching a channel on there starts the current program from its beginning rather than joining it live — Live TV hands a client a stream, not a position in one. For joining live, use the "TV-Sender" entry above. Saving asks Jellyfin to refresh its guide, which is what fills the Live TV section; it can also be run by hand under Scheduled Tasks → Refresh Guide.

Channels

Sets the schedule zero point to now, so the loop starts over with the first entry.
With more than one source, rotate through them taking this many items from each before moving on. For example, 2 with two series airs S1E1, S1E2, S2E1, S2E2, S1E3, S1E4, … Leave at 0 to play each source fully before the next (a marathon).
The shuffle is drawn once from the channel itself, never from the clock, so the guide and the player always agree and the order survives a restart.
With 30, a program starts only on the hour or the half hour and the rest of its slot is time to fill — which is what lets a block promise the film at 20:15. A program longer than one slot takes as many whole slots as it needs.
Trailers held in the library air on every client. Trailers the library only links to (usually YouTube) are played by the web client during the gap.

Program blocks

Parts of the week that air something else — the kids' programming until noon, the film on Saturday evening. Whatever no block covers airs the channel's own program above. A block picks up where it left off the last time it was on.
